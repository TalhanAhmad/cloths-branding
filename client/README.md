# Frontend Client

React + Tailwind CSS Frontend for LORA Clothing Brand

## Setup

```bash
npm install
```

## Running

**Development:**
```bash
npm start
```

Open `http://localhost:3000` in your browser.

**Production Build:**
```bash
npm run build
```

## Features

- ✅ React 18 with Hooks
- ✅ React Router v6
- ✅ Tailwind CSS Styling
- ✅ Responsive Design
- ✅ Shopping Cart with Zustand
- ✅ Product Filtering
- ✅ User Authentication
- ✅ WhatsApp Integration
- ✅ Admin Panel
- ✅ Mobile-First Design

## Environment

Create `.env.local` (optional):

```
REACT_APP_API_URL=http://localhost:5000/api
```

## Build & Deploy

**Vercel:**
```bash
npm run build
```

**Netlify:**
Push to GitHub, connect with Netlify

**AWS/GCP:**
Build and upload to your hosting

## Pages

- `/` - Homepage
- `/products` - Products Catalog
- `/products?category=Formal%20Wear` - Filtered Products
- `/cart` - Shopping Cart
- `/login` - Login/Register
- `/admin` - Admin Dashboard
